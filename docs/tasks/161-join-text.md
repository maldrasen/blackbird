I keep going back and forth on this resolution text. When a negotiation ends we show a final resolution message. This is a simple message showing the mechanical state, they run, they attack, or join.

The problem I'm seeing is that when a negotiation reaches a threshold or passes the interaction limit we don't have a step that shows that last decision point. That makes sense for an attack or run resolution, as the response text is clear enough. The monster doesn't need to say, "Okay I'm going to run away now."

When a monster joins the party though they should at least say that they've decided to do so. This is made clear in the join reactions, the join text is part of that reaction. When they join after a threshold is reached though all we see is a somewhat positive response to the last question, and then they join the party. What we need then is to show an interim message, after the resolution to join has been made, but before the resolution text is displayed, and only show this in the case when there's something to show.

The join text itself should come from the negotiation style, species or base monster. Choosing the most specific version as is done with the reactions.
