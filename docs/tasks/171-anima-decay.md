Anima and animus should decay over time. Useful as another limiter to how many characters you can reasonably have in training at a time. Decay should be linear, down to 0 I think because anima should be spent to increase sensitivity or add sexual preferences. Once anima is spent, the levels remain what they are and shouldn't decrease. This should happen when a character sleeps, so the character's schedule system needs to be in place first.
