I've been debating the best way to go about this from a story perspective. I want spells to be discovered in the dungeon, and I want them to be fairly random. Games like Wizardry traditionally let you pick a new spell when you level up, but I think it would be more roguelike to leave it to chance. 

Like the mana fonts, I think you should be able to find shrines in the dungeon. In order to learn a spell you need to perform a ritual at the shrine. I think eventually we'll have more involved episodes that describe these rituals in detail, but for now simply learning a spell at the shrine should be sufficient for this task. Also like the fonts the shrines will need their own feature type. 

We should actually have lots of different shrines, with each shrine having it's own selection of spells that you could learn. Some spells will have minimum intelligence or skill requirements, though the first spells you learn from any shrine shouldn't have a skill requirement so that you have some way of earning skill points. (Minimum intelligence is still possible.) A player also can't learn a spell that they don't have enough mana to cast it at power level 1.

Shrines will be themed for what kind of magic can be learned there. They might not all be mana color based. A "sneaky" shrine might teach blind and silence spells, but blind is a red effect and silence is blue. 

### Player Only
Only the player character is able to learn spells at a shrine this way. There's a clear difference between the way the dungeon interacts with the player and other humans and the way it interacts with it's own denizens. This is the same way the mana fonts work, so it only makes sense that leaning spells would follow the same pattern.

### Spell Count Limit
There should also be a limit to the number of spell any character can know. We could base this on their intelligence attribute or level, or both. We need some way of showing how many spells they can learn on the character details somewhere. Probably on a spellbook tab, which we can do as a separate task. We need a way to cast spells outside of combat as it is.

### Shrine Spawning
Not sure yet if I want to spawn shrines that a player can't learn any magic from. If they're not qualified to learn any new spells, or have already learned all the spells we could stop them from being placed in the dungeon. Or alternatively, the ritual you perform to learn a new spell simply doesn't work.
