I want to look at how the character cards are currently formatted.

The character bars in the battle are only showing the health bar, which worked for a time, but as we start adding spells and abilities that cost mana and stamina, we're going to need to show the bars for them as well. We're already using a horizontal layout in the inventory panel. I think we should use that same layout everywhere we show a character card, the battles, the party configuration, etc.
