I'm splitting 014 into two different tasks. The first task added the quiver component and ammunition requirements for bow attacks. The second half will focus on equipping ammunition in the User Interface. 

Unlike the rest of the equipment the ammunition is an article. Ammunition has a quantity and it's stored in the quiver component. In the interface though we can simply list it as another equipment slot. Selecting the ammunition slot will show all the ammo articles. Equipping and unequipping, showing ammo details, should all be comparable to how the equipment already works.
