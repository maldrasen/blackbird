We've updated the Status Effect System to handle the fixed time status effects, but nothing in the game applies them yet. The Kobold trapper seems like a good candidate to have some kind of blind, flash bang effect, using the "Blasto" grenades that were already added. We can even make these the first AoE items, though the targeting should probably remain, highest threat,  and just happens to include everyone around them. (Perhaps even the monster in the row in front of the character if they target someone in the first row)
