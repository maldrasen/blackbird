I'd like for the poised status to have some additional mechanical effects, giving the defend command more of a reason to use it. If a character is poised they already have advantage on their defend roll. I think they should also get advantage on their next attack and do 50% extra damage, making a defend then attack strategy viable. Some special abilities may require a poised status to use. 

In a similar fashion, the off balance status effect should be more impactful. It should give disadvantage on the first attack and do half damage. If a character starts their turn off balance, it would be much better to defend that turn, regain their poise then attack. 

In order to do this, we need for the poised and off balance status effects need to remain in effect during the player's turn. Currently, the turn count status effects are cleared right when a character starts their turn, but they need to remain until their action is chosen so that it can be applied to their command. The only other turnCount effect is stunned, which makes the character skip their turn, so it should work the same as their only option is to pass.
