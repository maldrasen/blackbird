We have a party configuration, but we need a way to edit it. We need to be able to change a character's position within the formation. A character can be put into any position at any time, but the formation is only valid when there are no characters in the back row without a character in front of them. We can highlight an empty front row in orange to indicate that it should be filled. This should mostly be a drag and drop interface. Dragging a character on top of another should swap them. We also need to be able to add and remove party members from the character roster, which can only be done while at home.
