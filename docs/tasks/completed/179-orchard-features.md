With the introduction of the Rhysh apples, we should sometimes add an orchard feature to the dungeon's upper floors. These features will trigger an episode for apple picking. Sometimes a group of monsters will be there already picking apples and will need to be negotiated with. An orchard should be a large square room with rows of tree graphics. The room size may effect how many apples can be harvested.
