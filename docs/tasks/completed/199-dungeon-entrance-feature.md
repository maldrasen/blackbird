When you enter the dungeon, the first room you land in could be any room. It's whatever room has the up stairs added to it. I'd like to change the floor builder to add a dungeon-entrance feature, only to the first level, and limit the first level to only allow one up stair. The dungeon entrance can have a unique shape or graphics, and its own unique description.
