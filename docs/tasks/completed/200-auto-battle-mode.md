The keyboard shortcuts help, but I think what we really need is an auto battle mode; a toggle button we can press to make the party members act automatically each round, and advances through the text automatically. The auto mode won't be intelligent. Just always choose basic attack and attack whoever is closest. Defend if an attack isn't possible. 

Another related option could be to toggle a focus target. Having a focus target set would skip the target step if the attack or ability can hit the targeted position. We can also skip the targeting step when there is only one valid target.
